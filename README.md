**Galería de Arte Interactiva**
Este proyecto forma parte del módulo de Fundamentos de Programación, donde se aplican los conocimientos adquiridos en HTML, CSS, Bootstrap y JavaScript para desarrollar una aplicación web interactiva y responsiva.

La aplicación permite explorar una galería de obras de arte, filtrarlas por categoría, ver los detalles de cada pieza, y contactar a los autores mediante un formulario validado.

---

**Objetivo General**
Desarrollar una aplicación web interactiva aplicando HTML, CSS, Bootstrap y JavaScript, asegurando un diseño responsivo y funcionalidades dinámicas.

---

**Objetivos Específicos**
Implementar lógica de programación en JavaScript para interactividad y manejo de datos.
Aplicar HTML, CSS y Bootstrap para un diseño estructurado y adaptable a diferentes dispositivos.
Desarrollar habilidades de resolución de problemas mediante la implementación de funcionalidades dinámicas.
Fomentar el trabajo en equipo y la organización de tareas en el desarrollo del proyecto.

## Páginas del Proyecto

### **Inicio (index.html)**
Presenta información general de los artistas y una introducción a la galería.  

### **Galería (galeria.html)**
Muestra una cuadrícula de miniaturas con posibilidad de:
- Buscar por título o autor.  
- Filtrar por categoría.  
- Acceder al detalle de cada obra.  

### **Detalle (detalles.html)**
Muestra información ampliada de la obra seleccionada:  
- Imagen en tamaño grande.  
- Título, autor, descripción y categoría.

### **Sobre Nosotros (sobre-nosotros.html)**
Incluye información del equipo y un formulario de contacto validado con JavaScript.

---
## Funcionalidades en JavaScript

- **Filtrado por categoría:** permite mostrar solo las obras de una categoría seleccionada.  
- **Vista detallada:** al hacer clic en una imagen, se abre una página con más información.  
- **Validación de formulario:** el formulario de contacto valida campos obligatorios antes de enviarse.
